The method

One loop, repeated at increasing complexity.

01Learn the theory
02Understand what it means physically
03Build something that demonstrates it
04Document what actually happened
05Increase complexity
  • Don't rush. Depth over course-completion speed.
  • Build while learning. Don't wait until the theory is finished.
  • Start simple. An LED is a legitimate Project 01.
  • Understand before abstracting. Know what a library does before leaning on it.
  • Write down the failures. The debugging is the content.
  • Connect it back. Every build ties to a robotics concept.
